# Cálculo del total de una compra

## Estudiante
Estefania LIzbeth Cevallos Muñoz

## Descripción
Este proyecto fue desarrollado en Python y permite calcular el total de una compra a partir del precio de un producto y la cantidad adquirida.
El programa utiliza una función llamada `calcular_total`, la cual recibe dos parámetros: precio y cantidad. La función realiza la multiplicación de ambos valores y devuelve el resultado mediante `return`.
El programa solicita los datos al usuario y muestra en pantalla el total correspondiente a la compra.
